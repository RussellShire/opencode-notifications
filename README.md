# Opencode Notification Plugin (Mac)
A quick installer to add a plugin to ~/.opencode/plugins/ so you get notifications when you're opencode requires permissions or is ready to be prompted.

There are also pop-ups if you allow notifications the terminal where you run opencode. See Mac Settings > Notifications

## Build
```chmod +x build.sh```

```./build.sh```

## Install

```chmod +x install-notifications```

```$ ./install-notifications```
